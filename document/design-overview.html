系统架构

前端不处理协议二进制
API 风格REST
实时推送WS
协议核心HSMS
公网入口Nginx
浏览器只接收 JSON 结构化数据，不直接处理 SECS-II Item 或 HSMS 数据帧。
REST 负责设备配置、连接控制、历史记录；WebSocket 负责状态变化、报文、报警实时推送。
C++ Host 服务维护设备会话、协议状态机、事件缓存和消息落库。
Nginx 对外统一暴露静态页面和后端接口。
Browser -> Nginx -> / static dist/ -> /api C++ REST service -> /ws C++ WebSocket gateway C++ Host Service |- DeviceManager |- HostSession |- SecsCodec |- GemService |- MessageStore |- WsHub
